# 📐 SketchCAD

[English](README.en.md) | **繁體中文**

> **次世代參數化建築資訊模型（BIM）核心系統**  
> 基於 Rust 打造，結合 2D 向量精確工程繪圖、3D 空間實體互動建模、BIM 智慧參數化構件與全局響應式連動系統。

## 🌟 核心設計理念

傳統工程設計常面臨 **2D 平面工程圖** 與 **3D 空間形體** 脫節、圖面與**工料預算明細表（Schedule）** 互不同步的痛點。修改一處尺寸，往往需要手動重新繪製平面、立面、剖面並重算造價。

**SketchCAD** 以 Rust 語言從零構建，立足於三大支柱：
1. **精確向量幾何**：雙精度浮點數（$f64$）幾何座標、圖層系統、端點吸附（Snap）與工程標註。
2. **直覺空間實體建模**：半邊拓撲網格、任意 3D 空間多邊形平面的一鍵推拉（Push-Pull）直接拉伸建模。
3. **BIM 智慧物件與全局連動（Reactive SSOT）**：透過有向無環圖（DAG）依賴追蹤，任何一處幾何或屬性變更，全視圖（平面/3D/明細表）100% 即時自動重新計算。

## ⚡ 核心功能特色

### 1. 🔄 全局響應式連動更新（Reactive Dependency Graph）
* **單一真理來源（Single Source of Truth, SSOT）**：每個幾何實體、開口、標註與算量行皆為依賴圖上的節點。
* **拓撲排序增量更新**：當拉動牆體節點或修改門扇寬度時，下游依賴之扣洞網格、投影線條與工程造價表自動循序重算，徹底消除人為脫節錯誤。

### 2. 🏛️ BIM 智慧物件（Smart Parametric Objects）
所有構件皆實作統一的 `BimElement` 特徵，同時提供 2D 符號、3D 實體網格與自動工程算量：
* **牆體（Wall）**：支援多層複合材質、基準高度與厚度。
* **結構柱（Column）** 與 **結構樑（Beam）**：混凝土/鋼構斷面規格、標準結構交叉剖面線符號與 3D 實體。
* **結構樓板（Slab）**：高程設定、板厚、坪數與混凝土澆置體積換算。
* **輕鋼架天花板（Ceiling）**：室內吊頂淨高、吊筋與板材面積計算。
* **直通樓梯（Stairs）**：具備層次分明之踏步級數、自動均分計算級高（Riser）與踏深（Tread）、前緣 25mm 踏步凸緣防滑條（Nosing）、鋸齒狀階梯側翼（Stepped Flanks）與梯腹結構厚度（120mm Waist Slab），徹底杜絕坡道化現象，由各角度觀看皆展現逼真階梯層次。
* **欄杆扶手（Railing）**：支援沿階梯坡度或平面邊界安裝、頂部主扶手管、底部防護桿、間距立柱與安全夾膠玻璃隔板。
* **門（Door）**：寄生於宿主牆體，具備 2D 90° 開啟迴轉弧線符號、3D 門板實體與開洞布林剪裁。
* **窗（Window）**：支援窗台高度（Sill Height）、氣密窗框與雙層中空玻璃材質。
* **雙坡屋頂（Roof）**：支援出挑挑簷、雙坡屋脊線、坡度（0°~60°）與防水保溫層厚度。
* **無障礙坡道（Ramp）**：符合法定 1:12 坡度比、爬升箭頭與防滑安全地坪。
* **結構單元式玻璃幕牆（Curtain Wall）**：鋁合金受力豎梃（Mullion）、橫樑網格分割與 Low-E 雙層中空隔音玻璃。
* **室內空間與房間區域標籤（Space / Zone）**：客廳、主臥、臥室、廚房、衛浴等空間用途劃定，自動計算實坪面積、**台灣專用坪數（坪 = $m^2 \times 0.3025$）**、踢腳板周長與空間淨空容積。
* **高精度室內家具與櫥櫃軟裝庫（High-Fidelity FF&E Furniture）**：拒絕粗糙立方體包裝盒，全面導入高擬真參數化多重幾何模型：
  * **雙人床組（Bed）**：床框底台、4 支床腳、厚實獨立筒床墊、典雅大板床頭板、繃布軟包裝飾飾板、雙枕頭與羽絨翻摺被褥。
  * **收納大衣櫃（Wardrobe）**：防潮踢腳板、櫃體結構、雙扇帶門縫大門片、現代極簡垂直金屬長把手與天花收頂封板。
  * **實木餐桌椅組（Dining Table）**：厚實實木桌面、桌底支撐邊框、4 支重型方柱桌腳，並配置環繞之 6 張北歐風實木餐椅（椅墊、4 腳與靠背）。
  * **系統廚具水槽料理台（Kitchen Cabinet）**：防潮黑色踢腳座、下櫃門片抽屜分層與金屬把手、厚石英石檯面、下嵌式不鏽鋼水槽、冷熱水鵝頸龍頭與雙口瓦斯爐/爐架。
  * **衛浴單體馬桶（Toilet）**：陶瓷儲水箱、水箱蓋、頂部雙段沖水按鈕、陶瓷底座盆體與人體工學緩降座圈蓋。
  * **客廳舒適沙發（Sofa）**：沙發金屬矮腳、實木托盤底盤、左右厚實扶手、高靠背、3 塊獨立高回彈座墊與靠枕。
  * **書房辦公書桌椅（Study Desk）**：加厚工作桌板、現代鋼製口字形桌腳、後側防隱私擋板、右側三層收納抽屜櫃附長條把手，以及專屬 5 爪人體工學旋轉電腦椅。
* **真實光學反射照明燈具系統（Lighting Fixtures & Photometrics）**：告別突兀的多角錐線框，實裝精緻燈具本體與柔和地面光斑照度：
  * **精緻燈具本體**：包含防眩崁孔修飾環與深杯（筒燈）、極細金屬吊線與簡約鐘形金屬燈罩（吊燈）、天花軌道與萬向轉向射燈筒（軌道燈）、超薄底盤與微凸大面柔光罩（吸頂燈）、隱藏鋁槽連續柔光條（燈帶）。
  * **自然柔和地面照度光斑（Floor Illumination Pool）**：在地面投射 24 邊形同心柔光漫射光斑（中心亮區與外圍衰減圈），完全消除多角錐黑邊線框（無任何惱人斜線稜脊），並隨色溫（Kelvin）呈現溫潤暖金、自然白或清涼冷色調光暈。

### 3. 🖥️ 次世代工程圖形操作介面（GUI）
* **3D 即時動態剖面切割盒（Real-Time 3D Section Cut）**：
  * 支援 X、Y、Z 三軸即時剖切滑桿，可一鍵切除屋頂與外牆，透視建築內部精緻的室內裝修、軟裝家具擺放與動線格局。
* **3D 渲染解析度與畫質設定（3D Quality & Resolution Settings）**：
  * **超採樣抗鋸齒解析度（SSAA）**：支援 `1.0x (標準清晰)`、`1.5x (高清細緻)`、`2.0x (Retina 極致雙倍取樣)`，徹底告別粗糙邊緣。
  * **空間著色模式**：擬真實體材質著色（Realistic Material Shading）、建築消隱線框（Hidden-Line Blueprint）、X-Ray 半透明空間透視。
  * **深度緩衝（Painter's Algorithm & Back-Face Culling）**：嚴格依相機視距由遠至近正確繪製，徹底解決模型重疊穿面與視角覆蓋問題。
  * **天花板鳥瞰透視保護**：鳥瞰視角自動玻璃化天花板，清楚透視建築內部直通樓梯、結構柱與陳設。
* **下方工程圖紙視圖切換器（Bottom Viewport Sheets）**：
  * 比照專業工程繪圖圖紙頁籤，置於視口底端方便單鍵即時切換：
    * 📑 `2D 平面工程圖 (Level 1 Plan)`
    * 🌐 `3D 空間實體模型 (3D Orbit Perspective)`
    * ◫ `雙視窗並排 (Split View 2D + 3D)`
* **Visual Studio 屬性設定格風格（Property Grid）**：
  * **分類邏輯群組**：幾何尺寸、空間與約束定位、材料與物理規範、工程造價與算量、BIM 識別資訊。
  * **雙欄排版**：左欄屬性名稱、右欄即時數值調節器（DragValue / ComboBox）。
  * **工具列與即時篩選**：支援「📑 分類排序」與「🔤 字母排序」，附帶屬性即時搜尋過濾框。
  * **底部屬性說明欄（Help Pane）**：滑鼠懸停於任意屬性時，動態顯示該 BIM 參數的工程規範定義與連動機制。
* **專案構件階層總管與 Photoshop 圖層可見度（Solution Explorer & Layers）**：
  * **階層樹狀結構**：將畫面上所有構件依工程類別（結構體工程、門窗開口、室內裝修動線）樹狀展開收合。
  * **Photoshop 風格眼睛切換（`👁` / `⊘`）**：每個構件與分類皆配備獨立可見度開關，點擊立即同步隱藏/顯示該構件於 2D 工程圖與 3D 空間模型中。
  * **樹狀節點展開編輯**：展開個別構件可直接進行快速尺寸微調，或選定後由下方屬性格進行完整修改。

### 4. 🛠️ 進階幾何核心演算法
* **空間平面推拉引擎（Push-Pull Direct Extrusion）**：
  * 採用**紐威爾法向量演算法（Newell's Method）**，支援空間任意傾斜平面的法向量計算。
  * 自動生成側壁四邊形網格（Quads）與頂/底蓋面，保證產出的 3D 模型為嚴格**水密實體（Watertight Solid）**。
* **實體開口布林剪裁（CSG Boolean Subtraction）**：
  * 門窗置入牆體時，自動執行空間分割，將牆體分解為開口前段、後段、窗下實體與上方過樑，在 3D 空間中真實開洞穿透。
* **建築扣洞淨算量（Net QTO）**：
  * 自動扣除所有門窗的開口淨空間，得出精確的淨混凝土澆置體積與雙面泥作粉刷模板面積。

### 4. 🌐 完整 OpenBIM 與 CAD 格式相容性（雙向開啟、匯出與專案存檔）
| 格式 | 支援程度 | 說明 |
| :---: | :---: | :--- |
| **SKC (.skc)** | **專案存檔 & 開啟** | SketchCAD 原生完整工程專案格式，完整保留所有 BIM 參數構件、材質設定、圖層可見度與工程量估驗清單。支援 `Ctrl+S` 與 `Ctrl+Shift+S`。 |
| **IFC4 (.ifc)** | **匯出 & 匯入雙向支援** | 遵循 ISO-10303-21 STEP 規範，雙向還原 `IFCWALL`、`IFCDOOR`、`IFCWINDOW`、`IFCCOLUMN`、`IFCBEAM`、`IFCSLAB`、`IFCCOVERING`、`IFCSTAIR`，具備 22 字元 IFC GUID 雙向還原能力。 |
| **DXF (.dxf)** | **匯出 & 開啟圖檔** | 支援標準 DXF 向量工程圖元（LINE, LWPOLYLINE），開啟時自動轉換為可編輯之智慧 BIM 牆體。 |
| **DWG (.dwg)** | **原生二進制解碼** | 純 Rust 位元流直接讀取，開啟時自動將 2D CAD 平面圖元轉換為 3D BIM 構件。 |
| **BCF 2.1 (.bcf/.bcfzip)** | **匯出 & 開啟封包** | BIM 協同議題標準（.bcf / .bcfzip），支援議題檢討、視角導航、狀態管理與構件關聯。 |

## 🏗️ 系統架構（Multi-Crate Architecture）

本專案採用 Rust Cargo Workspace 模組化設計：

```text
SketchCAD/
├── crates/
│   ├── sketchcad-core/      # 核心數學、單位系統(mm/m/坪)、UUID、響應式依賴圖(DAG)
│   ├── sketchcad-geom/      # 2D 向量草圖、半邊網格、Push-Pull 推拉、布林剪裁開洞
│   ├── sketchcad-bim/       # 智慧構件(Wall/Door/Window/Col/Beam/Slab/Ceiling/Stairs)、材質庫、工程算量(QTO)
│   ├── sketchcad-io/        # DXF、DWG、IFC4 STEP 解析與匯出、BCF 協同壓縮包
│   ├── sketchcad-render/    # 2D CAD 與 3D 軌道旋轉相機視口(Camera)座標變換
│   └── sketchcad-app/       # 整合應用程式入口與端到端驗證展示
├── exports/                 # 測試產出之 .dxf, .ifc, .bcfzip 檔案目錄
└── Cargo.toml               # 工作區虛擬清單 (Virtual Manifest)
```

## 🚀 快速上手

### 系統需求
* [Rust](https://www.rust-lang.org/) 1.80.0 或以上版本（支援最新 2021 Edition）。

### 1. 編譯與執行測試套件
執行全工作區單元測試（包含依賴圖傳播、IFC GUID 往返、布林開洞與 STEP 解析測試）：
```bash
cargo test --workspace
```

### 2. 啟動桌面端圖形操作介面（GUI）
啟動基於 `wgpu` + `egui` 的雙視窗互動式桌面應用程式（2D 工程平面畫布 + 3D 空間實體軌道視口 + 即時算量面板）：
```bash
cargo run -p sketchcad-app
```

### 3. 執行命令列管線驗證（Headless CLI）
如需在自動化測試環境或無 GUI 伺服器端執行全管線檢驗（包含 DWG 原生解析、IFC 往返、布林剪裁與算量）：
```bash
cargo run -p sketchcad-app -- --cli
```
